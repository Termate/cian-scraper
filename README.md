# Мониторинг аренды студий в Москве (ЦИАН)

## Описание проекта

Данный проект выполнен в рамках блока «Введение в web-разработку на Python».

Цель проекта — реализовать непрерывный сбор данных из интернета и провести анализ собранной информации.

Объект наблюдения:
- город: Москва
- округ: ЮВАО
- тип недвижимости: квартира-студия
- тип сделки: аренда
- источник: ЦИАН

Скрапер собирает данные с сайта, сохраняет их в базу данных SQLite и позволяет анализировать изменения во времени.

## Установка

Создание виртуального окружения:

python3 -m venv .venv

Активация:

source .venv/bin/activate

Установка зависимостей:

pip install -r requirements.txt

Установка браузера:

playwright install chromium

---

## Запуск проекта

### Один запуск скрапера

python -m src.main

После запуска данные сохраняются в:

data/raw/cian_studios.db

---

### Непрерывный запуск

python -m src.scheduler --hours 4

---

## Анализ данных

python -m src.analysis

Результаты сохраняются в:

data/artifacts/

---

## Какие данные собираются
